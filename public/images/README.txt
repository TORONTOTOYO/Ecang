YOUR IMAGES GO IN THIS FOLDER
=============================

  images/
    portrait/            -> your hero photo           (erica.jpg)
    projects/
      edel/              -> photos for the EDEL project  (cover.jpg, 1.jpg, 2.jpg, 3.jpg, 4.jpg)
      project-2/         -> photos for your 2nd project  (cover.jpg, 1.jpg ...)
      project-3/         -> photos for your 3rd project  (cover.jpg, 1.jpg ...)
    certificates/        -> your certificates            (cert-1.jpg, cert-2.jpg ...)

Save a file with the same name that src/data.js expects and it shows up
automatically. If a file is missing, the site shows a colored placeholder.

Using .png or another name? Just change the path in src/data.js.
Tip: keep each image under 500 KB so the page loads fast.
